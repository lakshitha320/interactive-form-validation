This project demonstrates real-time form validation, dynamic error handling, and modern responsive UI design.

# 📌 Project Overview

This project was developed as part of the **Front-End Development Internship Program** at **Codveda Technology**.

The main objective of this task was to build an interactive form with client-side validation using vanilla JavaScript while maintaining a clean and professional user interface.

---

# ✨ Features

✅ Real-time input validation
✅ Dynamic error messages
✅ Email format validation
✅ Password length validation
✅ Phone number validation
✅ Success message after submission
✅ Responsive design for mobile, tablet, and desktop
✅ Clean and modern UI
✅ User-friendly experience
